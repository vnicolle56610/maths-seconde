    Automatismes N11 — Fonctions de référence

    22 questions sans calculatrice, réparties en 4 séries courtes à faire en quelques minutes. Chercher d'abord seul, puis ouvrir le corrigé.

    ⚡ Faire le QCM interactif 📄 Diaporama PDF à projeter 📖 Revoir la notion

    Série A — Réactivation : carrés, racines et inverse

    ⏱ 6 min · Calculatrice interdite

    Consigne. Répondre rapidement. Garder les valeurs exactes.

    1. Calculer \(2^2\).
    2. Calculer \((-3)^2\).
    3. Calculer \(\sqrt{49}\).
    4. Résoudre \(x^2=9\).
    5. Donner l’ensemble de définition de \(f(x)=\dfrac{1}{x+1}\).
    6. Calculer \(|-5|\).
    Coup de pouce

    Conseils

    • Un carré est toujours positif ou nul.
    • Une racine carrée désigne le nombre positif.
    • Un dénominateur ne doit pas être nul.

    Vigilance

    • \(x^2=9\) a deux solutions.
    • \(\sqrt{9}=3\), pas \(-3\).
    • La valeur absolue est une distance.

    Corrigé de la série A

    1. \(\boxed{4}\).
    2. \(\boxed{9}\).
    3. \(\boxed{7}\).
    4. \(\boxed{x=-3\ \text{ou}\ x=3}\).
    5. \(x+1\neq0\), donc \(\boxed{\mathbb R\setminus\{-1\}}\).
    6. \(\boxed{5}\).
    Méthode. Pour les fonctions de référence, les calculs rapides reposent sur les définitions : carré, racine, inverse et valeur absolue.
    Vigilance. Ne pas confondre équation \(x^2=a\) et racine carrée \(\sqrt a\).

    Série B — Fonctions de référence : images

    ⏱ 6 min · Calculatrice interdite

    Consigne. Calculer rapidement les images demandées.

    1. Pour \(f(x)=x^2\), calculer \(f(-4)\).
    2. Pour \(g(x)=x^3\), calculer \(g(-2)\).
    3. Pour \(h(x)=\dfrac1x\), calculer \(h\!\left(\dfrac12\right)\).
    4. Pour \(r(x)=\sqrt{x}\), calculer \(r(81)\).
    5. Pour \(a(x)=|x|\), calculer \(a(-7)\).
    6. Pour \(p(x)=x^2-4\), calculer \(p(-3)\).
    Coup de pouce

    Conseils

    • Remplacer \(x\) par la valeur donnée.
    • Garder les parenthèses avec les nombres négatifs.
    • Pour l’inverse de \(\frac12\), penser à \(2\).

    Vigilance

    • \((-4)^2 eq -4^2\) si les parenthèses changent.
    • La racine carrée n’est définie que pour \(x\geqslant0\).
    • L’inverse de \(0\) n’existe pas.

    Corrigé de la série B

    1. \(f(-4)=(-4)^2=\boxed{16}\).
    2. \(g(-2)=(-2)^3=\boxed{-8}\).
    3. \(h\!\left(\dfrac12\right)=\)\(\dfrac{1}{1/2}=\)\(\boxed{2}\).
    4. \(r(81)=\)\(\sqrt{81}=\)\(\boxed{9}\).
    5. \(a(-7)=|-7|=\boxed{7}\).
    6. \(p(-3)=\)\((-3)^2-4=\)\(9-4=\)\(\boxed{5}\).
    Méthode. Pour calculer une image, on remplace \(x\) partout par la valeur demandée et on respecte les priorités.
    Vigilance. Les parenthèses sont indispensables quand on remplace par un nombre négatif.

    Série C — Fonctions de référence : équations et inéquations

    ⏱ 6 min · Calculatrice interdite

    Consigne. Résoudre rapidement. Donner l’ensemble des solutions.

    1. Résoudre \(x^2=16\).
    2. Résoudre \(x^2<9\).
    3. Résoudre \(\sqrt{x}=3\).
    4. Résoudre \(|x|=7\).
    5. Résoudre \(\dfrac1x=2\).
    6. Comparer \(2^2\) et \(5^2\).
    Coup de pouce

    Conseils

    • Utiliser les courbes ou la distance selon la forme.
    • Pour \(x^2<a\), penser à l’intervalle centré en \(0\).
    • Pour \(|x|=a\), deux solutions si \(a>0\).

    Vigilance

    • Toujours vérifier le domaine.
    • Multiplier par \(x\) demande de savoir que \(x eq0\).
    • La fonction carré n’est pas croissante sur tout \(\mathbb R\).

    Corrigé de la série C

    1. \(\boxed{x=-4\ \text{ou}\ x=4}\).
    2. \(\boxed{x\in]-3;3[}\).
    3. \(\sqrt{x}=\)\(3\Rightarrow \boxed{x=9}\).
    4. \(\boxed{x=-7\ \text{ou}\ x=7}\).
    5. \(\dfrac1x=\)\(2\Rightarrow 1=\)\(2x\Rightarrow \boxed{x=\dfrac12}\).
    6. \(4<25\), donc \(\boxed{2^2<5^2}\).
    Méthode. Les fonctions de référence permettent de résoudre rapidement des équations simples en reconnaissant la forme.
    Vigilance. Vérifier le domaine évite les solutions interdites.

    Série D — Type épreuve anticipée : QCM

    ⏱ 5 min · Calculatrice interdite

    Consigne. Choisir une seule réponse. Aucune justification n’est demandée.

    1. \((-6)^2=\)
      1. \(-36\)
      2. \(12\)
      3. \(36\)
      4. \(-12\)
    2. \(\sqrt{64}=\)
      1. \(-8\)
      2. \(8\)
      3. \(\pm8\)
      4. \(32\)
    3. Domaine de \(x\mapsto\sqrt{x-2}\) :
      1. \([2;+\infty[\)
      2. \(]-\infty;2]\)
      3. \(\mathbb R\)
      4. \(\mathbb R\setminus\{2\}\)
    4. Pour \(x>0\), si \(x\) augmente, \(\dfrac1x\) :
      1. augmente
      2. diminue
      3. reste constant
      4. devient nul
    Coup de pouce

    Conseils

    • Lire la structure avant de répondre.
    • Penser au domaine de définition.
    • Utiliser les fonctions de référence.

    Vigilance

    • La racine carrée est positive.
    • Une valeur absolue est positive.
    • L’inverse décroit sur \(]0;+\infty[\).

    Corrigé de la série D

    1. Réponse C : le carré d’un nombre négatif est positif.
    2. Réponse B : \(\sqrt{64}=8\).
    3. Réponse A : il faut \(x-2\geqslant0\).
    4. Réponse B : la fonction inverse décroit sur \(]0;+\infty[\).
    Méthode. Éliminer les réponses qui contredisent le domaine ou le signe attendu.
    Vigilance. La racine carrée est le nombre positif dont le carré vaut le nombre donné.
