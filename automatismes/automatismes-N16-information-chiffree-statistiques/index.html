    Automatismes N16 — Information chiffrée et statistiques

    24 questions sans calculatrice, réparties en 4 séries courtes à faire en quelques minutes. Chercher d'abord seul, puis ouvrir le corrigé.

    ⚡ Faire le QCM interactif 📄 Diaporama PDF à projeter 📖 Revoir la notion

    Série A — Réactivation – pourcentages et évolutions

    ⏱ 6 min · Calculatrice interdite

    Consigne. Répondre rapidement. Utiliser les coefficients multiplicateurs dès que possible.

    1. Calculer \(20\,\%\) de \(450\).
    2. Augmenter \(80\) de \(15\,\%\).
    3. Diminuer \(250\) de \(12\,\%\).
    4. Passer de \(0{,}37\) à un pourcentage.
    5. Un prix passe de \(40\) à \(50\) euros. Calculer le taux d'évolution.
    6. Calculer \(75\,\%\) de \(64\).
    Coup de pouce

    Conseils

    • Hausse de \(t\,\%\) : multiplier par \(1+\frac{t}{100}\).
    • Baisse de \(t\,\%\) : multiplier par \(1-\frac{t}{100}\).
    • Pour un taux, comparer l'écart à la valeur initiale.

    Vigilance

    • Le taux d'évolution se calcule toujours par rapport à la valeur de départ.
    • Ne pas confondre \(15\,\%\) et le coefficient \(1{,}15\).

    Corrigé de la série A

    1. \(0{,}20\times450=\)\(\boxed{90}\).
    2. Coefficient \(1{,}15\), donc \(80\times1{,}15=\)\(\boxed{92}\).
    3. Coefficient \(0{,}88\), donc \(250\times0{,}88=\)\(\boxed{220}\).
    4. \(0{,}37=\boxed{37\,\%}\).
    5. \(\dfrac{50-40}{40}=0{,}25\), donc \(\boxed{25\,\%}\).
    6. \(75\,\%=3/4\), donc \(\dfrac34\times64=\)\(\boxed{48}\).
    Méthode. Pour une évolution, remplacer l'expression longue par un coefficient multiplicateur. Pour un taux : \(\dfrac{\text{final}-\text{initial}}{\text{initial}}\).
    Vigilance. Une baisse de \(12\,\%\) ne signifie pas soustraire \(12\), mais soustraire \(12\,\%\) de la valeur de départ.

    Série B — Statistiques – moyenne, médiane, étendue

    ⏱ 6 min · Calculatrice interdite

    Consigne. Traiter les calculs sans calculatrice. Ranger les valeurs quand c'est nécessaire.

    1. Calculer la moyenne de \(6;8;10;12\).
    2. Donner la médiane de \(3;7;11;15;20\).
    3. Donner la médiane de \(4;8;10;18\).
    4. Calculer l'étendue de \(12;5;9;18;7\).
    5. Dans une série, la moyenne de \(10;14;16\) est-elle \(13\) ?
    6. Une note \(x\) complète \(8;12;16\) pour obtenir une moyenne de \(13\). Trouver \(x\).
    Coup de pouce

    Conseils

    • Moyenne : somme divisée par effectif total.
    • Médiane : ranger la série.
    • Étendue : maximum moins minimum.

    Vigilance

    • La médiane n'est pas toujours une valeur de la série.
    • La moyenne est sensible aux valeurs extrêmes.

    Corrigé de la série B

    1. \(\dfrac{6+8+10+12}{4}=\)\(\boxed{9}\).
    2. La valeur centrale est \(\boxed{11}\).
    3. \(\dfrac{8+10}{2}=\)\(\boxed{9}\).
    4. \(18-5=\boxed{13}\).
    5. \(\dfrac{10+14+16}{3}=\)\(\dfrac{40}{3}\), donc non.
    6. \(\dfrac{8+12+16+x}{4}=13\), donc \(36+x=52\), \(x=\boxed{16}\).
    Méthode. Identifier d'abord l'indicateur demandé. Pour une médiane, le rangement est obligatoire ; pour une moyenne, l'effectif total doit être clair.
    Vigilance. Sur une série de quatre valeurs, la médiane est la moyenne des deux valeurs centrales.

    Série C — Séries avec effectifs

    ⏱ 7 min · Calculatrice interdite

    Consigne. Utiliser les effectifs. Ne pas oublier de calculer l'effectif total.

    1. Valeurs \(2;5;8\), effectifs \(3;4;1\). Donner l'effectif total.
    2. Avec la série précédente, calculer la moyenne.
    3. Dans une classe : \(12\) filles et \(18\) garçons. Quelle proportion de filles ?
    4. Un groupe de \(20\) élèves contient \(6\) internes. Donner la fréquence des internes.
    5. Une série a moyenne \(15\) et effectif \(6\). Quelle est la somme des valeurs ?
    6. Valeurs \(1;2;3\), effectifs \(5;3;2\). Quelle valeur est majoritaire ?
    Coup de pouce

    Conseils

    • Une valeur répétée compte plusieurs fois.
    • Moyenne pondérée : valeur \(\times\) effectif.
    • Une fréquence est une proportion.

    Vigilance

    • Ne pas diviser par le nombre de valeurs différentes.
    • Diviser par l'effectif total.

    Corrigé de la série C

    1. \(3+4+1=\boxed{8}\).
    2. \(\dfrac{2\times3+5\times4+8\times1}{8}=\)\(\dfrac{34}{8}=\)\(\boxed{4{,}25}\).
    3. \(\dfrac{12}{30}=\)\(\dfrac25=\)\(\boxed{40\,\%}\).
    4. \(\dfrac{6}{20}=\)\(\dfrac{3}{10}=\)\(\boxed{0{,}30}\), soit \(\boxed{30\,\%}\).
    5. \(\text{somme}=\)\(15\times6=\)\(\boxed{90}\).
    6. L'effectif le plus grand est \(5\), donc valeur \(\boxed{1}\).
    Méthode. Pour une série avec effectifs, construire mentalement un tableau : valeurs, effectifs, produits valeur \(\times\) effectif, puis totaliser.
    Vigilance. Le nombre de valeurs différentes n'est pas l'effectif total.

    Série D — Type épreuve anticipée – QCM statistiques

    ⏱ 5 min · Calculatrice interdite

    Consigne. Choisir une seule réponse. Aucune justification n'est demandée.

    1. Hausse de \(8\,\%\) : A \(0{,}08\) ; B \(0{,}92\) ; C \(1{,}08\) ; D \(8\).
    2. Baisse de \(30\,\%\) : A \(0{,}30\) ; B \(0{,}70\) ; C \(1{,}30\) ; D \(-0{,}30\).
    3. Moyenne de \(4;10;16\) : A \(10\) ; B \(12\) ; C \(30\) ; D \(8\).
    4. Médiane de \(2;5;9;13;20\) : A \(5\) ; B \(9\) ; C \(13\) ; D \(20\).
    5. Étendue de \(7;12;3;18\) : A \(21\) ; B \(15\) ; C \(11\) ; D \(18\).
    6. \(3\) élèves sur \(25\) : A \(3\,\%\) ; B \(12\,\%\) ; C \(25\,\%\) ; D \(75\,\%\).
    Coup de pouce

    Conseils

    • En QCM, éliminer les réponses impossibles.
    • Vérifier si l'on demande un coefficient, une proportion ou un pourcentage.

    Vigilance

    • La réponse \(0{,}08\) n'est pas le coefficient d'une hausse de \(8\,\%\).
    • Pour un pourcentage, ramener à \(100\) si possible.

    Corrigé de la série D

    1. réponse C : \(1+0{,}08=1{,}08\).
    2. réponse B : \(1-0{,}30=0{,}70\).
    3. réponse A : \((4+10+16)/3=10\).
    4. réponse B : la valeur centrale est \(9\).
    5. réponse B : \(18-3=15\).
    6. réponse B : \(3/25=12/100\).
    Méthode. Le QCM demande surtout de reconnaître rapidement la bonne grandeur : coefficient, moyenne, médiane, étendue ou fréquence.
    Vigilance. Un résultat numérique peut être exact mais répondre à une autre question.
