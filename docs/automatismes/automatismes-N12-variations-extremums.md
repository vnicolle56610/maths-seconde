## Série A — Réactivation : lire des variations

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** On sait que <span class="arithmatex">\(f\)</span> est croissante sur <span class="arithmatex">\([-2;1]\)</span>, décroissante sur <span class="arithmatex">\([1;4]\)</span>, avec <span class="arithmatex">\(f(-2)=0\)</span>, <span class="arithmatex">\(f(1)=5\)</span>, <span class="arithmatex">\(f(4)=2\)</span>. Répondre rapidement.
</div>

<ol class="auto-questions">
<li value="1">Donner le maximum de <span class="arithmatex">\(f\)</span> sur <span class="arithmatex">\([-2;4]\)</span>.</li>
<li value="2">Pour quelles valeurs de <span class="arithmatex">\(x\)</span> ce maximum est-il atteint ?</li>
<li value="3">Donner le minimum de <span class="arithmatex">\(f\)</span> sur <span class="arithmatex">\([-2;4]\)</span>.</li>
<li value="4">Comparer <span class="arithmatex">\(f(0)\)</span> et <span class="arithmatex">\(f(1)\)</span>.</li>
<li value="5">Comparer <span class="arithmatex">\(f(2)\)</span> et <span class="arithmatex">\(f(4)\)</span>.</li>
<li value="6">Peut-on affirmer que <span class="arithmatex">\(f(3)=3\)</span> ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Repérer les extrémités et les changements de sens.</li><li>Sur un intervalle croissant, les images sont rangées dans le même ordre.</li><li>Une variation ne donne pas toutes les valeurs exactes.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Un maximum est une valeur de <span class="arithmatex">\(f(x)\)</span>, pas une valeur de <span class="arithmatex">\(x\)</span>.</li><li>Distinguer la valeur atteinte et l’endroit où elle est atteinte.</li><li>Une comparaison n’est pas un calcul exact.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1">Le maximum vaut <span class="arithmatex">\(\boxed{5}\)</span>.</li>
    <li value="2">Il est atteint pour <span class="arithmatex">\(\boxed{x=1}\)</span>.</li>
    <li value="3">Le minimum vaut <span class="arithmatex">\(\boxed{0}\)</span>.</li>
    <li value="4">Comme <span class="arithmatex">\(0&lt;1\)</span> et <span class="arithmatex">\(f\)</span> est croissante sur <span class="arithmatex">\([-2;1]\)</span>, <span class="arithmatex">\(\boxed{f(0)&lt;f(1)}\)</span>.</li>
    <li value="5">Comme <span class="arithmatex">\(2&lt;4\)</span> et <span class="arithmatex">\(f\)</span> est décroissante sur <span class="arithmatex">\([1;4]\)</span>, <span class="arithmatex">\(\boxed{f(2)&gt;f(4)}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{\text{non}}\)</span> : les variations ne donnent pas cette valeur exacte.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Un tableau de variations donne des sens de variation, des comparaisons et parfois des extremums.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas inventer une valeur non donnée par le tableau ou le graphique.</div>

## Série B — Fonctions de référence : variations

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre rapidement avec les fonctions de référence.
</div>

<ol class="auto-questions">
<li value="1">La fonction carré est-elle croissante sur <span class="arithmatex">\([0;+\infty[\)</span> ?</li>
<li value="2">La fonction carré est-elle croissante sur <span class="arithmatex">\(\mathbb R\)</span> ?</li>
<li value="3">Sur <span class="arithmatex">\(]0;+\infty[\)</span>, la fonction inverse est-elle croissante ou décroissante ?</li>
<li value="4">La fonction racine carrée est-elle croissante sur <span class="arithmatex">\([0;+\infty[\)</span> ?</li>
<li value="5">Comparer <span class="arithmatex">\(\sqrt{5}\)</span> et <span class="arithmatex">\(\sqrt{7}\)</span>.</li>
<li value="6">Comparer <span class="arithmatex">\(\dfrac{1}{3}\)</span> et <span class="arithmatex">\(\dfrac{1}{8}\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Utiliser le sens de variation connu.</li><li>Pour comparer, éviter les valeurs décimales inutiles.</li><li>Inverse : plus le nombre positif est grand, plus son inverse est petit.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>La fonction carré change de sens en <span class="arithmatex">\(0\)</span>.</li><li>La racine carrée n’existe pas sur les négatifs.</li><li>Attention au sens inverse avec <span class="arithmatex">\(\frac1x\)</span>.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{\text{oui}}\)</span>, elle est croissante sur <span class="arithmatex">\([0;+\infty[\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{\text{non}}\)</span>, elle est décroissante sur <span class="arithmatex">\(]-\infty;0]\)</span> puis croissante sur <span class="arithmatex">\([0;+\infty[\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{\text{décroissante}}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{\text{oui}}\)</span>.</li>
    <li value="5">Comme <span class="arithmatex">\(5&lt;7\)</span> et <span class="arithmatex">\(\sqrt{x}\)</span> est croissante, <span class="arithmatex">\(\boxed{\sqrt5&lt;\sqrt7}\)</span>.</li>
    <li value="6">Comme <span class="arithmatex">\(3&lt;8\)</span> et <span class="arithmatex">\(x\mapsto \dfrac1x\)</span> décroit sur <span class="arithmatex">\(]0;+\infty[\)</span>, <span class="arithmatex">\(\boxed{\dfrac13&gt;\dfrac18}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour comparer deux images, utiliser le sens de variation plutôt que calculer des approximations.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le sens de variation dépend de l’intervalle considéré.</div>

## Série C — Extremums et encadrements

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre rapidement à partir des informations données.
</div>

<ol class="auto-questions">
<li value="1">Si <span class="arithmatex">\(x\in[2;5]\)</span> et <span class="arithmatex">\(f\)</span> est croissante, encadrer <span class="arithmatex">\(f(x)\)</span> avec <span class="arithmatex">\(f(2)=1\)</span> et <span class="arithmatex">\(f(5)=9\)</span>.</li>
<li value="2">Si <span class="arithmatex">\(x\in[-1;3]\)</span> et <span class="arithmatex">\(g\)</span> est décroissante, encadrer <span class="arithmatex">\(g(x)\)</span> avec <span class="arithmatex">\(g(-1)=7\)</span> et <span class="arithmatex">\(g(3)=2\)</span>.</li>
<li value="3">Pour <span class="arithmatex">\(p(x)=(x-2)^2+1\)</span>, donner le minimum évident.</li>
<li value="4">Pour <span class="arithmatex">\(p(x)=(x-2)^2+1\)</span>, pour quelle valeur de <span class="arithmatex">\(x\)</span> ce minimum est-il atteint ?</li>
<li value="5">Sur <span class="arithmatex">\([0;6]\)</span>, <span class="arithmatex">\(A(x)=x(6-x)\)</span>. Calculer <span class="arithmatex">\(A(3)\)</span>.</li>
<li value="6">Sur <span class="arithmatex">\([0;6]\)</span>, <span class="arithmatex">\(A(x)=x(6-x)\)</span>. Quelle valeur de <span class="arithmatex">\(x\)</span> semble donner l’aire maximale ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Une fonction croissante conserve l’ordre.</li><li>Une fonction décroissante inverse l’ordre des images.</li><li>Un carré est toujours positif ou nul.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Un encadrement porte sur les images.</li><li>Un minimum est une valeur atteinte.</li><li>La question 6 demande un réflexe de symétrie, pas une preuve complète.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1">Comme <span class="arithmatex">\(f\)</span> est croissante, <span class="arithmatex">\(\boxed{1\leqslant f(x)\leqslant 9}\)</span>.</li>
    <li value="2">Comme <span class="arithmatex">\(g\)</span> est décroissante, <span class="arithmatex">\(\boxed{2\leqslant g(x)\leqslant 7}\)</span>.</li>
    <li value="3"><span class="arithmatex">\((x-2)^2\geqslant0\)</span>, donc le minimum est <span class="arithmatex">\(\boxed{1}\)</span>.</li>
    <li value="4">Il est atteint pour <span class="arithmatex">\(\boxed{x=2}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(A(3)=3(6-3)=\boxed{9}\)</span>.</li>
    <li value="6">Par symétrie entre <span class="arithmatex">\(0\)</span> et <span class="arithmatex">\(6\)</span>, l’aire semble maximale pour <span class="arithmatex">\(\boxed{x=3}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Les extremums se lisent ou se déduisent souvent avec un carré positif, une symétrie ou un tableau de variations.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas confondre encadrer <span class="arithmatex">\(x\)</span> et encadrer <span class="arithmatex">\(f(x)\)</span>.</div>

## Série D — Type épreuve anticipée : QCM

<p class="auto-meta">⏱ 5 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification n’est demandée.
</div>

<ol class="auto-questions">
<li value="1">Si <span class="arithmatex">\(f\)</span> est croissante et <span class="arithmatex">\(2&lt;5\)</span>, alors :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(f(2)&gt;f(5)\)</span></li><li><span class="arithmatex">\(f(2)&lt;f(5)\)</span></li><li><span class="arithmatex">\(f(2)=f(5)\)</span></li><li>impossible</li></ol></li>
<li value="2">Le maximum d’une fonction est :<ol class="auto-choix" type="A"><li>une abscisse</li><li>une ordonnée</li><li>un intervalle</li><li>une courbe</li></ol></li>
<li value="3">La fonction <span class="arithmatex">\(x\mapsto x^2\)</span> est décroissante sur :<ol class="auto-choix" type="A"><li><span class="arithmatex">\([0;+\infty[\)</span></li><li><span class="arithmatex">\(]-\infty;0]\)</span></li><li><span class="arithmatex">\(\mathbb R\)</span></li><li><span class="arithmatex">\([1;+\infty[\)</span></li></ol></li>
<li value="4">Minimum évident de <span class="arithmatex">\((x+1)^2+4\)</span> :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(-1\)</span></li><li><span class="arithmatex">\(0\)</span></li><li><span class="arithmatex">\(4\)</span></li><li><span class="arithmatex">\(5\)</span></li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Identifier si la réponse est une valeur, une abscisse ou un intervalle.</li><li>Utiliser les fonctions de référence.</li><li>Un carré est toujours positif ou nul.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Le maximum est une valeur de la fonction.</li><li>Une fonction décroissante inverse l’ordre.</li><li>Une réponse peut être du mauvais type.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : une fonction croissante conserve l’ordre.</li>
    <li value="2"><strong class="auto-resultat">Réponse B</strong> : le maximum est une valeur atteinte.</li>
    <li value="3"><strong class="auto-resultat">Réponse B</strong> : le carré décroît sur <span class="arithmatex">\(]-\infty;0]\)</span>.</li>
    <li value="4"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\((x+1)^2\geq0\)</span>, donc le minimum est <span class="arithmatex">\(4\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> En QCM de variations, vérifier la nature de la réponse : image, antécédent, sens de variation ou encadrement.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une réponse plausible peut être du mauvais type mathématique.</div>
