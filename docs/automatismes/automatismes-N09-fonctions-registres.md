## Série A — Réactivation : images et antécédents

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre rapidement. Préciser image ou antécédent.
</div>

<ol class="auto-questions">
<li value="1">Pour <span class="arithmatex">\(f(x)=2x-3\)</span>, calculer <span class="arithmatex">\(f(4)\)</span>.</li>
<li value="2">Pour <span class="arithmatex">\(f(x)=2x-3\)</span>, déterminer l’antécédent de <span class="arithmatex">\(5\)</span>.</li>
<li value="3">Si <span class="arithmatex">\(g(3)=0\)</span>, quelle est l’image de <span class="arithmatex">\(3\)</span> par <span class="arithmatex">\(g\)</span> ?</li>
<li value="4">Pour <span class="arithmatex">\(h(x)=x^2+2x\)</span>, calculer <span class="arithmatex">\(h(-1)\)</span>.</li>
<li value="5">Résoudre <span class="arithmatex">\(x+2=0\)</span>.</li>
<li value="6">Donner l’ensemble de définition de <span class="arithmatex">\(k(x)=\dfrac{1}{x-4}\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Identifier la forme avant de calculer.</li><li>Écrire seulement les étapes utiles.</li><li>Contrôler le signe et les unités.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Image : on remplace <span class="arithmatex">\(x\)</span>.</li><li>Antécédent : on résout une équation.</li><li>Un dénominateur ne doit pas être nul.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(f(4)=\)</span><wbr><span class="arithmatex">\(2\times4-3=\)</span><wbr><span class="arithmatex">\(\boxed{5}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(2x-3=\)</span><wbr><span class="arithmatex">\(5\Rightarrow 2x=\)</span><wbr><span class="arithmatex">\(8\Rightarrow \boxed{x=4}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{0}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(h(-1)=1-2=\boxed{-1}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\boxed{x=-2}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{\mathbb{R}\setminus\{4\}}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Image et antécédent ne se lisent pas dans le même sens : l'image part de <span class="arithmatex">\(x\)</span>, l'antécédent part d'une valeur de <span class="arithmatex">\(f(x)\)</span>.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> La valeur interdite vient toujours de l'annulation du dénominateur.</div>

## Série B — Registres : tableau, formule, programme

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Passer d’un registre à l’autre.
</div>

<ol class="auto-questions">
<li value="1">Compléter : pour <span class="arithmatex">\(f(x)=x^2-1\)</span>, <span class="arithmatex">\(f(-2)=\ldots\)</span>, <span class="arithmatex">\(f(0)=\ldots\)</span>, <span class="arithmatex">\(f(3)=\ldots\)</span>.</li>
<li value="2">Dans le tableau <span class="arithmatex">\(x:-1;0;2\)</span> et <span class="arithmatex">\(f(x):4;1;-5\)</span>, donner l’image de <span class="arithmatex">\(2\)</span>.</li>
<li value="3">Dans ce même tableau, donner un antécédent de <span class="arithmatex">\(1\)</span>.</li>
<li value="4">Un programme multiplie le nombre par <span class="arithmatex">\(3\)</span>, puis soustrait <span class="arithmatex">\(4\)</span>. Donner <span class="arithmatex">\(f(x)\)</span>.</li>
<li value="5">Si <span class="arithmatex">\(f(2)=7\)</span>, quel point appartient à la courbe de <span class="arithmatex">\(f\)</span> ?</li>
<li value="6">Le point <span class="arithmatex">\((1\,;\,0)\)</span> appartient à <span class="arithmatex">\(\mathcal C_f\)</span>. Traduire avec <span class="arithmatex">\(f\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Tableau : première ligne pour <span class="arithmatex">\(x\)</span>, deuxième pour <span class="arithmatex">\(f(x)\)</span>.</li><li>Courbe : un point <span class="arithmatex">\((a;b)\)</span> signifie <span class="arithmatex">\(f(a)=b\)</span>.</li><li>Programme : écrire les opérations dans l'ordre.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas inverser abscisse et ordonnée.</li><li>Un antécédent n'est pas forcément unique.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(f(-2)=3\)</span>, <span class="arithmatex">\(f(0)=-1\)</span>, <span class="arithmatex">\(f(3)=8\)</span>. <span class="arithmatex">\(\boxed{3\,;\,-1\,;\,8}\)</span></li>
    <li value="2"><span class="arithmatex">\(\boxed{-5}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{0}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{f(x)=3x-4}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\boxed{(2\,;\,7)}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{f(1)=0}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Chaque registre donne la même information sous une forme différente : phrase, tableau, formule, courbe ou programme.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Un point de la courbe se lit toujours <span class="arithmatex">\((x\,;\,f(x))\)</span>.</div>

## Série C — Lecture graphique

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Utiliser le graphique de la fonction <span class="arithmatex">\(f\)</span> ci-dessous.
</div>

<ol class="auto-questions">
<li value="1"><div class="auto-figure"><img src="../figures/N09-fonctions-registres-b922a0b834.svg" alt="Figure de la série C" width="353"></div></li>
<li value="2">Lire <span class="arithmatex">\(f(2)\)</span>.</li>
<li value="3">Donner les antécédents de <span class="arithmatex">\(0\)</span> visibles sur le graphique.</li>
<li value="4">Donner la plus petite valeur atteinte sur l’intervalle représenté.</li>
<li value="5">Donner la plus grande valeur atteinte sur l’intervalle représenté.</li>
<li value="6">Vrai ou faux : <span class="arithmatex">\(f(0)=0\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Image : partir de l'axe horizontal puis lire l'ordonnée.</li><li>Antécédent : partir de l'axe vertical puis lire l'abscisse.</li><li>Maximum/minimum : chercher les hauteurs extrêmes.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Lire sur les axes, pas « à l'œil ».</li><li>Plusieurs antécédents sont possibles.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1">Le graphique représente la fonction <span class="arithmatex">\(f\)</span> sur l'intervalle affiché.</li>
    <li value="2"><span class="arithmatex">\(\boxed{f(2)=2}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{-2\text{ et }1}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{-2}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\boxed{3}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{\text{faux}}\)</span>, car <span class="arithmatex">\(f(0)=-1\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Une lecture graphique doit toujours préciser si l'on cherche une abscisse ou une ordonnée.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le point <span class="arithmatex">\((0\,;\,-1)\)</span> indique <span class="arithmatex">\(f(0)=-1\)</span>, pas <span class="arithmatex">\(f(0)=0\)</span>.</div>

## Série D — Type épreuve anticipée : QCM

<p class="auto-meta">⏱ 5 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification n’est demandée.
</div>

<ol class="auto-questions">
<li value="1">Si <span class="arithmatex">\(f(3)=7\)</span>, alors la courbe de <span class="arithmatex">\(f\)</span> passe par :<ol class="auto-choix" type="A"><li><span class="arithmatex">\((7\,;\,3)\)</span></li><li><span class="arithmatex">\((3\,;\,7)\)</span></li><li><span class="arithmatex">\((3\,;\,0)\)</span></li><li><span class="arithmatex">\((0\,;\,7)\)</span></li></ol></li>
<li value="2">Pour <span class="arithmatex">\(h(x)=x^2\)</span>, les antécédents de <span class="arithmatex">\(9\)</span> sont :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(3\)</span></li><li><span class="arithmatex">\(-3\)</span></li><li><span class="arithmatex">\(-3\)</span> et <span class="arithmatex">\(3\)</span></li><li><span class="arithmatex">\(81\)</span></li></ol></li>
<li value="3">L'ensemble de définition de <span class="arithmatex">\(k(x)=\dfrac{1}{x+2}\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(\mathbb R\)</span></li><li><span class="arithmatex">\(\mathbb R\setminus\{2\}\)</span></li><li><span class="arithmatex">\(\mathbb R\setminus\{-2\}\)</span></li><li><span class="arithmatex">\(\{ -2\}\)</span></li></ol></li>
<li value="4">Pour <span class="arithmatex">\(f(x)=-2x+5\)</span>, l'image de <span class="arithmatex">\(-1\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(3\)</span></li><li><span class="arithmatex">\(-7\)</span></li><li><span class="arithmatex">\(7\)</span></li><li><span class="arithmatex">\(-3\)</span></li></ol></li>
<li value="5">Dans le tableau <span class="arithmatex">\(x:0;1;2\)</span>, <span class="arithmatex">\(f(x):3;5;7\)</span>, un antécédent de <span class="arithmatex">\(5\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(0\)</span></li><li><span class="arithmatex">\(1\)</span></li><li><span class="arithmatex">\(2\)</span></li><li><span class="arithmatex">\(7\)</span></li></ol></li>
<li value="6">« Ajouter <span class="arithmatex">\(2\)</span>, puis élever au carré » correspond à :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(x^2+2\)</span></li><li><span class="arithmatex">\(x+4\)</span></li><li><span class="arithmatex">\((x+2)^2\)</span></li><li><span class="arithmatex">\(2x^2\)</span></li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Repérer si la question demande une image ou un antécédent.</li><li>Vérifier les valeurs interdites.</li><li>Pour un programme, conserver l'ordre des opérations.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li><span class="arithmatex">\(x^2=9\)</span> a deux solutions.</li><li><span class="arithmatex">\((x+2)^2\neq x^2+2\)</span>.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\((3\,;\,7)\)</span></li>
    <li value="2"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(-3\)</span> et <span class="arithmatex">\(3\)</span></li>
    <li value="3"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(\mathbb R\setminus\{-2\}\)</span></li>
    <li value="4"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(7\)</span></li>
    <li value="5"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(1\)</span></li>
    <li value="6"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\((x+2)^2\)</span></li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Un QCM de fonctions se traite souvent en traduisant d'abord l'énoncé en notation mathématique.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Attention aux carrés : deux nombres opposés peuvent avoir la même image.</div>
