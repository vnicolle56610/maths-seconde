## Série A — Réactivation : carrés, racines et inverse

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre rapidement. Garder les valeurs exactes.
</div>

<ol class="auto-questions">
<li value="1">Calculer <span class="arithmatex">\(2^2\)</span>.</li>
<li value="2">Calculer <span class="arithmatex">\((-3)^2\)</span>.</li>
<li value="3">Calculer <span class="arithmatex">\(\sqrt{49}\)</span>.</li>
<li value="4">Résoudre <span class="arithmatex">\(x^2=9\)</span>.</li>
<li value="5">Donner l’ensemble de définition de <span class="arithmatex">\(f(x)=\dfrac{1}{x+1}\)</span>.</li>
<li value="6">Calculer <span class="arithmatex">\(|-5|\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Un carré est toujours positif ou nul.</li><li>Une racine carrée désigne le nombre positif.</li><li>Un dénominateur ne doit pas être nul.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li><span class="arithmatex">\(x^2=9\)</span> a deux solutions.</li><li><span class="arithmatex">\(\sqrt{9}=3\)</span>, pas <span class="arithmatex">\(-3\)</span>.</li><li>La valeur absolue est une distance.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{4}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{9}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{7}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{x=-3\ \text{ou}\ x=3}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(x+1\neq0\)</span>, donc <span class="arithmatex">\(\boxed{\mathbb R\setminus\{-1\}}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{5}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour les fonctions de référence, les calculs rapides reposent sur les définitions : carré, racine, inverse et valeur absolue.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas confondre équation <span class="arithmatex">\(x^2=a\)</span> et racine carrée <span class="arithmatex">\(\sqrt a\)</span>.</div>

## Série B — Fonctions de référence : images

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Calculer rapidement les images demandées.
</div>

<ol class="auto-questions">
<li value="1">Pour <span class="arithmatex">\(f(x)=x^2\)</span>, calculer <span class="arithmatex">\(f(-4)\)</span>.</li>
<li value="2">Pour <span class="arithmatex">\(g(x)=x^3\)</span>, calculer <span class="arithmatex">\(g(-2)\)</span>.</li>
<li value="3">Pour <span class="arithmatex">\(h(x)=\dfrac1x\)</span>, calculer <span class="arithmatex">\(h\!\left(\dfrac12\right)\)</span>.</li>
<li value="4">Pour <span class="arithmatex">\(r(x)=\sqrt{x}\)</span>, calculer <span class="arithmatex">\(r(81)\)</span>.</li>
<li value="5">Pour <span class="arithmatex">\(a(x)=|x|\)</span>, calculer <span class="arithmatex">\(a(-7)\)</span>.</li>
<li value="6">Pour <span class="arithmatex">\(p(x)=x^2-4\)</span>, calculer <span class="arithmatex">\(p(-3)\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Remplacer <span class="arithmatex">\(x\)</span> par la valeur donnée.</li><li>Garder les parenthèses avec les nombres négatifs.</li><li>Pour l’inverse de <span class="arithmatex">\(\frac12\)</span>, penser à <span class="arithmatex">\(2\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li><span class="arithmatex">\((-4)^2 eq -4^2\)</span> si les parenthèses changent.</li><li>La racine carrée n’est définie que pour <span class="arithmatex">\(x\geqslant0\)</span>.</li><li>L’inverse de <span class="arithmatex">\(0\)</span> n’existe pas.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(f(-4)=(-4)^2=\boxed{16}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(g(-2)=(-2)^3=\boxed{-8}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(h\!\left(\dfrac12\right)=\)</span><wbr><span class="arithmatex">\(\dfrac{1}{1/2}=\)</span><wbr><span class="arithmatex">\(\boxed{2}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(r(81)=\)</span><wbr><span class="arithmatex">\(\sqrt{81}=\)</span><wbr><span class="arithmatex">\(\boxed{9}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(a(-7)=|-7|=\boxed{7}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(p(-3)=\)</span><wbr><span class="arithmatex">\((-3)^2-4=\)</span><wbr><span class="arithmatex">\(9-4=\)</span><wbr><span class="arithmatex">\(\boxed{5}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour calculer une image, on remplace <span class="arithmatex">\(x\)</span> partout par la valeur demandée et on respecte les priorités.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Les parenthèses sont indispensables quand on remplace par un nombre négatif.</div>

## Série C — Fonctions de référence : équations et inéquations

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Résoudre rapidement. Donner l’ensemble des solutions.
</div>

<ol class="auto-questions">
<li value="1">Résoudre <span class="arithmatex">\(x^2=16\)</span>.</li>
<li value="2">Résoudre <span class="arithmatex">\(x^2&lt;9\)</span>.</li>
<li value="3">Résoudre <span class="arithmatex">\(\sqrt{x}=3\)</span>.</li>
<li value="4">Résoudre <span class="arithmatex">\(|x|=7\)</span>.</li>
<li value="5">Résoudre <span class="arithmatex">\(\dfrac1x=2\)</span>.</li>
<li value="6">Comparer <span class="arithmatex">\(2^2\)</span> et <span class="arithmatex">\(5^2\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Utiliser les courbes ou la distance selon la forme.</li><li>Pour <span class="arithmatex">\(x^2&lt;a\)</span>, penser à l’intervalle centré en <span class="arithmatex">\(0\)</span>.</li><li>Pour <span class="arithmatex">\(|x|=a\)</span>, deux solutions si <span class="arithmatex">\(a&gt;0\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Toujours vérifier le domaine.</li><li>Multiplier par <span class="arithmatex">\(x\)</span> demande de savoir que <span class="arithmatex">\(x eq0\)</span>.</li><li>La fonction carré n’est pas croissante sur tout <span class="arithmatex">\(\mathbb R\)</span>.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{x=-4\ \text{ou}\ x=4}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{x\in]-3;3[}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\sqrt{x}=\)</span><wbr><span class="arithmatex">\(3\Rightarrow \boxed{x=9}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{x=-7\ \text{ou}\ x=7}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\dfrac1x=\)</span><wbr><span class="arithmatex">\(2\Rightarrow 1=\)</span><wbr><span class="arithmatex">\(2x\Rightarrow \boxed{x=\dfrac12}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(4&lt;25\)</span>, donc <span class="arithmatex">\(\boxed{2^2&lt;5^2}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Les fonctions de référence permettent de résoudre rapidement des équations simples en reconnaissant la forme.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Vérifier le domaine évite les solutions interdites.</div>

</div>

<li value="2"><span class="arithmatex">\(\sqrt{64}=\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(-8\)</span></li><li><span class="arithmatex">\(8\)</span></li><li><span class="arithmatex">\(\pm8\)</span></li><li><span class="arithmatex">\(32\)</span></li></ol></li>
<li value="3">Domaine de <span class="arithmatex">\(x\mapsto\sqrt{x-2}\)</span> :<ol class="auto-choix" type="A"><li><span class="arithmatex">\([2;+\infty[\)</span></li><li><span class="arithmatex">\(]-\infty;2]\)</span></li><li><span class="arithmatex">\(\mathbb R\)</span></li><li><span class="arithmatex">\(\mathbb R\setminus\{2\}\)</span></li></ol></li>
<li value="4">Pour <span class="arithmatex">\(x&gt;0\)</span>, si <span class="arithmatex">\(x\)</span> augmente, <span class="arithmatex">\(\dfrac1x\)</span> :<ol class="auto-choix" type="A"><li>augmente</li><li>diminue</li><li>reste constant</li><li>devient nul</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Lire la structure avant de répondre.</li><li>Penser au domaine de définition.</li><li>Utiliser les fonctions de référence.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>La racine carrée est positive.</li><li>Une valeur absolue est positive.</li><li>L’inverse décroit sur <span class="arithmatex">\(]0;+\infty[\)</span>.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse C</strong> : le carré d’un nombre négatif est positif.</li>
    <li value="2"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(\sqrt{64}=8\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse A</strong> : il faut <span class="arithmatex">\(x-2\geqslant0\)</span>.</li>
    <li value="4"><strong class="auto-resultat">Réponse B</strong> : la fonction inverse décroit sur <span class="arithmatex">\(]0;+\infty[\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Éliminer les réponses qui contredisent le domaine ou le signe attendu.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> La racine carrée est le nombre positif dont le carré vaut le nombre donné.</div>
