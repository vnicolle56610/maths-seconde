## Série A — Réactivation : signes et équations

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre rapidement. Repérer la structure avant de calculer.
</div>

<ol class="auto-questions">
<li value="1">Factoriser <span class="arithmatex">\(x^2-9\)</span>.</li>
<li value="2">Résoudre <span class="arithmatex">\(3x-6=0\)</span>.</li>
<li value="3">Donner le signe de <span class="arithmatex">\(2x-8\)</span> pour <span class="arithmatex">\(x=3\)</span>, puis pour <span class="arithmatex">\(x=5\)</span>.</li>
<li value="4">Pour <span class="arithmatex">\(f(x)=x^2-4\)</span>, calculer <span class="arithmatex">\(f(-2)\)</span> et <span class="arithmatex">\(f(1)\)</span>.</li>
<li value="5">Résoudre <span class="arithmatex">\(x^2=16\)</span>.</li>
<li value="6">Résoudre <span class="arithmatex">\(|x-1|=3\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Chercher d'abord une identité remarquable.</li><li>Un carré donne souvent deux solutions.</li><li>Une valeur absolue représente une distance.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas oublier la solution négative d'une équation <span class="arithmatex">\(x^2=a\)</span>.</li><li>Un signe se lit sur des intervalles, pas seulement en un point.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(x^2-9=(x-3)(x+3)\)</span>, donc <span class="arithmatex">\(\boxed{(x-3)(x+3)}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(3x=6\)</span>, donc <span class="arithmatex">\(\boxed{x=2}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(2\times3-8=-2&lt;0\)</span> ; <span class="arithmatex">\(2\times5-8=2&gt;0\)</span>.</li>
    <li value="4"><span class="arithmatex">\(f(-2)=0\)</span> et <span class="arithmatex">\(f(1)=-3\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\boxed{x=-4\text{ ou }x=4}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(|x-1|=3\)</span> signifie <span class="arithmatex">\(x-1=3\)</span> ou <span class="arithmatex">\(x-1=-3\)</span>, donc <span class="arithmatex">\(\boxed{x=4\text{ ou }x=-2}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Identifier la forme : facteur commun, identité remarquable, équation affine, carré ou valeur absolue.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une solution trouvée doit toujours être vérifiée mentalement dans l'énoncé.</div>

## Série B — Tableaux de signes

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Donner les signes ou les ensembles de solutions sous forme d'intervalles.
</div>

<ol class="auto-questions">
<li value="1">Dresser le signe de <span class="arithmatex">\(x-2\)</span> sur <span class="arithmatex">\(\mathbb R\)</span>.</li>
<li value="2">Dresser le signe de <span class="arithmatex">\(-3x+6\)</span> sur <span class="arithmatex">\(\mathbb R\)</span>.</li>
<li value="3">Dresser le signe de <span class="arithmatex">\((x-2)(x+1)\)</span>.</li>
<li value="4">Résoudre <span class="arithmatex">\((x-2)(x+1)&gt;0\)</span>.</li>
<li value="5">Pour <span class="arithmatex">\(\dfrac{x-4}{x+2}\)</span>, donner la valeur interdite et les zéros.</li>
<li value="6">Résoudre <span class="arithmatex">\(\dfrac{x-4}{x+2}\geqslant0\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Chercher d'abord les valeurs qui annulent chaque facteur.</li><li>Une valeur interdite se place dans le tableau mais n'est jamais solution.</li><li>Multiplier les signes ligne par ligne.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Pour un quotient, le dénominateur ne doit pas être nul.</li><li>Les bornes incluses dépendent de <span class="arithmatex">\(&gt;\)</span>, <span class="arithmatex">\(\geqslant\)</span> et des valeurs interdites.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(x-2&lt;0\)</span> sur <span class="arithmatex">\(\boxed{]-\infty;2[}\)</span>, nul en <span class="arithmatex">\(2\)</span>, positif sur <span class="arithmatex">\(\boxed{]2;+\infty[}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(-3x+6=0\)</span> pour <span class="arithmatex">\(x=2\)</span> ; signe <span class="arithmatex">\(+\)</span> avant <span class="arithmatex">\(2\)</span>, signe <span class="arithmatex">\(-\)</span> après <span class="arithmatex">\(2\)</span>.</li>
    <li value="3">Zéros : <span class="arithmatex">\(-1\)</span> et <span class="arithmatex">\(2\)</span>. Le produit est <span class="arithmatex">\(+\)</span> sur <span class="arithmatex">\(]-\infty;-1[\cup]2;+\infty[\)</span>, <span class="arithmatex">\(-\)</span> sur <span class="arithmatex">\(]-1;2[\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{]-\infty;-1[\cup]2;+\infty[}\)</span>.</li>
    <li value="5">Valeur interdite : <span class="arithmatex">\(\boxed{x=-2}\)</span>. Zéro du numérateur : <span class="arithmatex">\(\boxed{x=4}\)</span>.</li>
    <li value="6">Le quotient est <span class="arithmatex">\(\geqslant0\)</span> sur <span class="arithmatex">\(\boxed{]-\infty;-2[\cup[4;+\infty[}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Dans un tableau de signes, on commence par les valeurs remarquables : zéros et valeurs interdites.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une valeur interdite est toujours exclue, même si le signe semble convenir.</div>

## Série C — Équations et inéquations de fonctions

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une méthode rapide : calcul, lecture d'un tableau de signes ou interprétation graphique.
</div>

<ol class="auto-questions">
<li value="1">Si <span class="arithmatex">\(f(x)=2x+1\)</span>, résoudre <span class="arithmatex">\(f(x)=7\)</span>.</li>
<li value="2">Si <span class="arithmatex">\(g(x)=x^2\)</span>, résoudre <span class="arithmatex">\(g(x)=9\)</span>.</li>
<li value="3">Deux courbes se coupent pour <span class="arithmatex">\(x=-1\)</span> et <span class="arithmatex">\(x=3\)</span>. Résoudre <span class="arithmatex">\(f(x)=g(x)\)</span>.</li>
<li value="4">On sait que <span class="arithmatex">\(f(x)-g(x)\)</span> est positif sur <span class="arithmatex">\(]-\infty;1]\cup[4;+\infty[\)</span>. Résoudre <span class="arithmatex">\(f(x)\geqslant g(x)\)</span>.</li>
<li value="5">Résoudre <span class="arithmatex">\(\dfrac{x+1}{x-3}=0\)</span>.</li>
<li value="6">Résoudre <span class="arithmatex">\(x^2-4\leqslant0\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li><span class="arithmatex">\(f(x)=g(x)\)</span> se lit comme une intersection.</li><li>Pour comparer <span class="arithmatex">\(f\)</span> et <span class="arithmatex">\(g\)</span>, étudier le signe de <span class="arithmatex">\(f-g\)</span>.</li><li>Un quotient est nul quand son numérateur est nul et son dénominateur non nul.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas confondre <span class="arithmatex">\(f(x)=g(x)\)</span> et <span class="arithmatex">\(f(x)\geqslant g(x)\)</span>.</li><li>Pour <span class="arithmatex">\(x^2\leq a\)</span>, les solutions sont souvent entre deux bornes.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(2x+1=7\)</span>, donc <span class="arithmatex">\(2x=6\)</span>, <span class="arithmatex">\(\boxed{x=3}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(x^2=9\)</span>, donc <span class="arithmatex">\(\boxed{x=-3\text{ ou }x=3}\)</span>.</li>
    <li value="3">Les solutions sont les abscisses d'intersection : <span class="arithmatex">\(\boxed{\{-1;3\}}\)</span>.</li>
    <li value="4">Les solutions sont <span class="arithmatex">\(\boxed{]-\infty;1]\cup[4;+\infty[}\)</span>.</li>
    <li value="5">Numérateur nul : <span class="arithmatex">\(x=-1\)</span>, et <span class="arithmatex">\(-1\neq3\)</span>. Solution : <span class="arithmatex">\(\boxed{x=-1}\)</span>.</li>
    <li value="6"><span class="arithmatex">\((x-2)(x+2)\leqslant0\)</span>, donc <span class="arithmatex">\(\boxed{[-2;2]}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Une équation de fonctions se traduit par une égalité d'images ; une inéquation se traduit par une comparaison.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Pour un quotient, vérifier le domaine avant d'annoncer une solution.</div>

## Série D — Type épreuve anticipée : QCM

<p class="auto-meta">⏱ 5 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification n'est demandée.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\((x-3)(x+2)&gt;0\)</span> a pour solutions :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(]-3;2[\)</span></li><li><span class="arithmatex">\(]-\infty;-2[\cup]3;+\infty[\)</span></li><li><span class="arithmatex">\(]-2;3[\)</span></li><li><span class="arithmatex">\([-2;3]\)</span></li></ol></li>
<li value="2"><span class="arithmatex">\(\dfrac{x-1}{x+4}\)</span> n'est pas défini pour :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(x=1\)</span></li><li><span class="arithmatex">\(x=-4\)</span></li><li><span class="arithmatex">\(x=4\)</span></li><li><span class="arithmatex">\(x=-1\)</span></li></ol></li>
<li value="3">Si <span class="arithmatex">\(f-g&gt;0\)</span> sur <span class="arithmatex">\(]2;5[\)</span>, alors :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(f&lt;g\)</span></li><li><span class="arithmatex">\(f=g\)</span></li><li><span class="arithmatex">\(f&gt;g\)</span></li><li><span class="arithmatex">\(g&gt;f\)</span></li></ol></li>
<li value="4">Les solutions de <span class="arithmatex">\(x^2-1=0\)</span> sont :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(1\)</span></li><li><span class="arithmatex">\(-1\)</span></li><li><span class="arithmatex">\(-1\)</span> et <span class="arithmatex">\(1\)</span></li><li>aucune</li></ol></li>
<li value="5">Une courbe coupe l'axe des abscisses en <span class="arithmatex">\(-2\)</span> et <span class="arithmatex">\(4\)</span>. Alors <span class="arithmatex">\(f(x)=0\)</span> pour :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(x=0\)</span></li><li><span class="arithmatex">\(x=-2\)</span> ou <span class="arithmatex">\(4\)</span></li><li><span class="arithmatex">\(x=2\)</span></li><li>tout <span class="arithmatex">\(x\)</span></li></ol></li>
<li value="6">Pour résoudre <span class="arithmatex">\(f(x)\leqslant g(x)\)</span>, on étudie le signe de :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(f+g\)</span></li><li><span class="arithmatex">\(fg\)</span></li><li><span class="arithmatex">\(f-g\)</span></li><li><span class="arithmatex">\(\dfrac{f}{g}\)</span></li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Éliminer les réponses impossibles.</li><li>Revenir au sens du symbole : zéro, signe, comparaison.</li><li>Sur un quotient, regarder le dénominateur.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas inclure une valeur interdite.</li><li>Un produit est positif si les deux facteurs ont le même signe.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : Zéros <span class="arithmatex">\(-2\)</span> et <span class="arithmatex">\(3\)</span>, produit positif à l'extérieur.</li>
    <li value="2"><strong class="auto-resultat">Réponse B</strong> : Le dénominateur <span class="arithmatex">\(x+4\)</span> s'annule pour <span class="arithmatex">\(x=-4\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(f-g&gt;0\)</span> signifie <span class="arithmatex">\(f&gt;g\)</span>.</li>
    <li value="4"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(x^2-1=(x-1)(x+1)\)</span>.</li>
    <li value="5"><strong class="auto-resultat">Réponse B</strong> : Les zéros sont les abscisses des points de l'axe des abscisses.</li>
    <li value="6"><strong class="auto-resultat">Réponse C</strong> : On résout <span class="arithmatex">\(f-g\leqslant0\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> En QCM, la reconnaissance de la structure évite les calculs longs.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une réponse rapide doit rester compatible avec le domaine de définition.</div>
