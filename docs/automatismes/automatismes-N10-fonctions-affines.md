## Série A — Réactivation : calculs et équations

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre rapidement. Écrire seulement l’étape qui sécurise le calcul.
</div>

<ol class="auto-questions">
<li value="1">Simplifier <span class="arithmatex">\(3(x-2)+2x\)</span>.</li>
<li value="2">Factoriser <span class="arithmatex">\(5x+15\)</span>.</li>
<li value="3">Résoudre <span class="arithmatex">\(2x-7=5\)</span>.</li>
<li value="4">Pour <span class="arithmatex">\(f(x)=4x-1\)</span>, calculer <span class="arithmatex">\(f(3)\)</span>.</li>
<li value="5">Calculer <span class="arithmatex">\(\dfrac{3}{4}+\dfrac{1}{8}\)</span>.</li>
<li value="6">Déterminer le coefficient directeur de la droite passant par <span class="arithmatex">\(A(1;2)\)</span> et <span class="arithmatex">\(B(4;8)\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Développer avant de réduire.</li><li>Factoriser par le facteur commun.</li><li>Pour une pente : variation verticale sur variation horizontale.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas oublier le signe du terme constant.</li><li>Une équation se transforme des deux côtés.</li><li>Le coefficient directeur peut être une fraction.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(3x-6+2x=\boxed{5x-6}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(5x+15=5(x+3)\)</span>, donc <span class="arithmatex">\(\boxed{5(x+3)}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(2x=12\)</span>, donc <span class="arithmatex">\(\boxed{x=6}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(f(3)=\)</span><wbr><span class="arithmatex">\(4\times3-1=\)</span><wbr><span class="arithmatex">\(\boxed{11}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\dfrac{3}{4}+\dfrac{1}{8}=\)</span><wbr><span class="arithmatex">\(\dfrac{6}{8}+\dfrac{1}{8}=\)</span><wbr><span class="arithmatex">\(\boxed{\dfrac78}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(m=\)</span><wbr><span class="arithmatex">\(\dfrac{8-2}{4-1}=\)</span><wbr><span class="arithmatex">\(\boxed{2}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Identifier d’abord la nature de la tâche : réduire, factoriser, résoudre, calculer une image ou lire une pente.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le coefficient directeur mesure une variation : il n’est pas toujours l’ordonnée à l’origine.</div>

## Série B — Fonctions affines : expression

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre rapidement. Identifier coefficient directeur et ordonnée à l’origine.
</div>

<ol class="auto-questions">
<li value="1">Pour <span class="arithmatex">\(f(x)=-2x+7\)</span>, donner le coefficient directeur.</li>
<li value="2">Pour <span class="arithmatex">\(g(x)=4x-3\)</span>, donner <span class="arithmatex">\(g(0)\)</span>.</li>
<li value="3">Donner l’expression d’une fonction affine de coefficient directeur <span class="arithmatex">\(5\)</span> et d’ordonnée à l’origine <span class="arithmatex">\(-1\)</span>.</li>
<li value="4">Une fonction affine <span class="arithmatex">\(h\)</span> a pour coefficient directeur <span class="arithmatex">\(3\)</span> et <span class="arithmatex">\(h(2)=7\)</span>. Déterminer <span class="arithmatex">\(h(x)\)</span>.</li>
<li value="5">Une fonction affine <span class="arithmatex">\(u\)</span> vérifie <span class="arithmatex">\(u(1)=2\)</span> et <span class="arithmatex">\(u(4)=11\)</span>. Déterminer son coefficient directeur.</li>
<li value="6">Pour <span class="arithmatex">\(v(x)=-x+6\)</span>, calculer l’antécédent de <span class="arithmatex">\(0\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Écrire une fonction affine sous la forme <span class="arithmatex">\(ax+b\)</span>.</li><li>Le coefficient directeur est <span class="arithmatex">\(a\)</span>.</li><li>L’ordonnée à l’origine est <span class="arithmatex">\(b=f(0)\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas confondre <span class="arithmatex">\(a\)</span> et <span class="arithmatex">\(b\)</span>.</li><li>Pour déterminer <span class="arithmatex">\(b\)</span>, utiliser une valeur connue.</li><li>Un antécédent se trouve en résolvant une équation.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{a=-2}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(g(0)=\)</span><wbr><span class="arithmatex">\(4\times0-3=\)</span><wbr><span class="arithmatex">\(\boxed{-3}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{f(x)=5x-1}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(h(x)=3x+b\)</span> et <span class="arithmatex">\(6+b=7\)</span>, donc <span class="arithmatex">\(b=1\)</span> : <span class="arithmatex">\(\boxed{h(x)=3x+1}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(a=\)</span><wbr><span class="arithmatex">\(\dfrac{11-2}{4-1}=\)</span><wbr><span class="arithmatex">\(\boxed{3}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(-x+6=\)</span><wbr><span class="arithmatex">\(0\Rightarrow \boxed{x=6}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour une fonction affine, la forme utile est <span class="arithmatex">\(f(x)=ax+b\)</span>. Deux informations permettent de déterminer les deux nombres <span class="arithmatex">\(a\)</span> et <span class="arithmatex">\(b\)</span>.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> L’ordonnée à l’origine n’est pas l’image de <span class="arithmatex">\(1\)</span>, mais l’image de <span class="arithmatex">\(0\)</span>.</div>

## Série C — Fonctions affines : variations et signe

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre rapidement. Traduire le signe du coefficient directeur.
</div>

<ol class="auto-questions">
<li value="1">Si <span class="arithmatex">\(f(x)=2x-5\)</span>, la fonction est-elle croissante ou décroissante ?</li>
<li value="2">Si <span class="arithmatex">\(g(x)=-3x+6\)</span>, la fonction est-elle croissante ou décroissante ?</li>
<li value="3">Résoudre <span class="arithmatex">\(-3x+6=0\)</span>.</li>
<li value="4">Donner le signe de <span class="arithmatex">\(-3x+6\)</span> pour <span class="arithmatex">\(x&lt;2\)</span>.</li>
<li value="5">Le point <span class="arithmatex">\(A(2;1)\)</span> appartient-il à la droite d’équation <span class="arithmatex">\(y=-x+3\)</span> ?</li>
<li value="6">Si <span class="arithmatex">\(a&lt;0\)</span>, comparer <span class="arithmatex">\(f(4)\)</span> et <span class="arithmatex">\(f(7)\)</span> pour une fonction affine de coefficient directeur <span class="arithmatex">\(a\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Regarder le signe de <span class="arithmatex">\(a\)</span>.</li><li>Pour le signe, commencer par résoudre <span class="arithmatex">\(f(x)=0\)</span>.</li><li>Tester l’appartenance d’un point en remplaçant <span class="arithmatex">\(x\)</span> et <span class="arithmatex">\(y\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Quand <span class="arithmatex">\(a&lt;0\)</span>, la fonction est décroissante.</li><li>Le zéro de la fonction change le signe.</li><li>Un point est un couple <span class="arithmatex">\((x;y)\)</span>.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(a=2&gt;0\)</span>, donc <span class="arithmatex">\(\boxed{\text{croissante}}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(a=-3&lt;0\)</span>, donc <span class="arithmatex">\(\boxed{\text{décroissante}}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(-3x+6=\)</span><wbr><span class="arithmatex">\(0\Rightarrow -3x=\)</span><wbr><span class="arithmatex">\(-6\Rightarrow \boxed{x=2}\)</span>.</li>
    <li value="4">Pour <span class="arithmatex">\(x&lt;2\)</span>, <span class="arithmatex">\(-3x+6&gt;0\)</span>, donc <span class="arithmatex">\(\boxed{\text{positif}}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(-2+3=1\)</span>, donc <span class="arithmatex">\(\boxed{\text{oui}}\)</span>.</li>
    <li value="6">Comme <span class="arithmatex">\(4&lt;7\)</span> et <span class="arithmatex">\(f\)</span> est décroissante, <span class="arithmatex">\(\boxed{f(4)&gt;f(7)}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Une fonction affine de coefficient directeur positif est croissante ; négatif, elle est décroissante. Son signe se lit autour de sa racine.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Dans une inégalité, le raisonnement par variations évite souvent des calculs inutiles.</div>

## Série D — Type épreuve anticipée : QCM

<p class="auto-meta">⏱ 5 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification n’est demandée.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(f(x)=3x-2\)</span>. Image de <span class="arithmatex">\(4\)</span> ?<ol class="auto-choix" type="A"><li><span class="arithmatex">\(10\)</span></li><li><span class="arithmatex">\(12\)</span></li><li><span class="arithmatex">\(14\)</span></li><li><span class="arithmatex">\(-10\)</span></li></ol></li>
<li value="2">Coefficient directeur de <span class="arithmatex">\(f(x)=-5x+1\)</span> ?<ol class="auto-choix" type="A"><li><span class="arithmatex">\(-5\)</span></li><li><span class="arithmatex">\(1\)</span></li><li><span class="arithmatex">\(5\)</span></li><li><span class="arithmatex">\(-1\)</span></li></ol></li>
<li value="3">La fonction <span class="arithmatex">\(x\mapsto -4x+8\)</span> est :<ol class="auto-choix" type="A"><li>croissante</li><li>décroissante</li><li>constante</li><li>positive</li></ol></li>
<li value="4">Antécédent de <span class="arithmatex">\(10\)</span> par <span class="arithmatex">\(f(x)=x+3\)</span> ?<ol class="auto-choix" type="A"><li><span class="arithmatex">\(7\)</span></li><li><span class="arithmatex">\(10\)</span></li><li><span class="arithmatex">\(13\)</span></li><li><span class="arithmatex">\(-7\)</span></li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Image : remplacer <span class="arithmatex">\(x\)</span>.</li><li>Coefficient directeur : coefficient de <span class="arithmatex">\(x\)</span>.</li><li>Antécédent : résoudre une équation.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Une seule réponse correcte.</li><li>Ne pas confondre <span class="arithmatex">\(a\)</span> et <span class="arithmatex">\(b\)</span>.</li><li>Une fonction décroissante a <span class="arithmatex">\(a&lt;0\)</span>.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse A</strong> : <span class="arithmatex">\(f(4)=12-2=10\)</span>.</li>
    <li value="2"><strong class="auto-resultat">Réponse A</strong> : le coefficient de <span class="arithmatex">\(x\)</span> est <span class="arithmatex">\(-5\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse B</strong> : le coefficient directeur est négatif.</li>
    <li value="4"><strong class="auto-resultat">Réponse A</strong> : <span class="arithmatex">\(x+3=10\)</span>, donc <span class="arithmatex">\(x=7\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Repérer le type de question : image, antécédent, coefficient directeur ou variation.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une réponse rapide doit rester contrôlée.</div>
