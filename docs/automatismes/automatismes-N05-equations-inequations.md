## Série A — Réactivation : calculs et équations

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre rapidement. Les solutions sont données dans <span class="arithmatex">\(\mathbb R\)</span>.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(\dfrac{5}{6}-\dfrac{1}{3}\)</span></li>
<li value="2"><span class="arithmatex">\((-2)^3\)</span></li>
<li value="3">Résoudre : <span class="arithmatex">\(x-8=3\)</span>.</li>
<li value="4">Résoudre : <span class="arithmatex">\(5x=20\)</span>.</li>
<li value="5">Développer : <span class="arithmatex">\(-2(x-6)\)</span>.</li>
<li value="6">Calculer <span class="arithmatex">\(3^2-5^2\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Réduire les fractions.</li><li>Isoler l'inconnue par opérations équivalentes.</li><li>Utiliser les identités si elles apparaissent.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Une puissance impaire conserve le signe.</li><li>Pour une équation, chaque transformation doit conserver les solutions.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\dfrac{5}{6}-\dfrac{1}{3}=\)</span><wbr><span class="arithmatex">\(\dfrac{5}{6}-\dfrac{2}{6}=\)</span><wbr><span class="arithmatex">\(\boxed{\dfrac12}\)</span>.</li>
    <li value="2"><span class="arithmatex">\((-2)^3=\boxed{-8}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(x-8=3 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( \boxed{x=11}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(5x=20 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( \boxed{x=4}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(-2(x-6)=\boxed{-2x+12}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(3^2-5^2=9-25=\boxed{-16}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Isoler <span class="arithmatex">\(x\)</span> revient à annuler les opérations qui l'entourent.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas changer une équation en une expression sans signe égal.</div>

## Série B — Équations et inéquations du premier degré

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Résoudre dans <span class="arithmatex">\(\mathbb R\)</span>.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(2x+5=17\)</span></li>
<li value="2"><span class="arithmatex">\(7-3x=1\)</span></li>
<li value="3"><span class="arithmatex">\(4x-9&lt;3\)</span></li>
<li value="4"><span class="arithmatex">\(-2x+1\geqslant 9\)</span></li>
<li value="5"><span class="arithmatex">\(5(x-1)=2x+7\)</span></li>
<li value="6"><span class="arithmatex">\(\dfrac{x}{3}-2=4\)</span></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Regrouper les termes en <span class="arithmatex">\(x\)</span>.</li><li>Diviser en dernier.</li><li>Si on divise par un nombre négatif, le sens change.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Une inéquation se conclut par un intervalle ou une phrase claire.</li><li>Le sens de l'inégalité est fragile.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(2x+5=17 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( 2x=12 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( \boxed{x=6}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(7-3x=1 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( -3x=-6 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( \boxed{x=2}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(4x-9&lt;3 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( 4x&lt;12 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( \boxed{x&lt;3}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(-2x+1\geqslant9 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( -2x\geqslant8 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( \boxed{x\leqslant -4}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(5x-5=2x+7 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( 3x=12 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( \boxed{x=4}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\dfrac{x}{3}-2=4 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( \dfrac{x}{3}=6 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( \boxed{x=18}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Les transformations se font par équivalences pour conserver exactement les solutions.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Diviser par un nombre négatif inverse le sens de l'inégalité.</div>

## Série C — Produit nul, quotient et contraintes

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Résoudre ou donner l'ensemble des valeurs interdites.
</div>

<ol class="auto-questions">
<li value="1">Résoudre : <span class="arithmatex">\((x-4)(x+2)=0\)</span>.</li>
<li value="2">Résoudre : <span class="arithmatex">\(x(3x-6)=0\)</span>.</li>
<li value="3">Résoudre : <span class="arithmatex">\(\dfrac{x-5}{2x+1}=0\)</span>.</li>
<li value="4">Donner la valeur interdite de <span class="arithmatex">\(\dfrac{3x+1}{x-7}\)</span>.</li>
<li value="5">Résoudre : <span class="arithmatex">\(\dfrac{2}{x+3}=0\)</span>.</li>
<li value="6">Résoudre : <span class="arithmatex">\((x-1)^2=0\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Un produit est nul si un facteur est nul.</li><li>Un quotient est nul si son numérateur est nul et son dénominateur non nul.</li><li>Chercher d'abord les valeurs interdites.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Le dénominateur ne doit jamais être nul.</li><li><span class="arithmatex">\(\dfrac{2}{x+3}=0\)</span> n'a pas de solution.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(x-4=0\)</span> ou <span class="arithmatex">\(x+2=0\)</span>, donc <span class="arithmatex">\(\boxed{x=4\text{ ou }x=-2}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(x=0\)</span> ou <span class="arithmatex">\(3x-6=0\)</span>, donc <span class="arithmatex">\(\boxed{x=0\text{ ou }x=2}\)</span>.</li>
    <li value="3">Numérateur nul : <span class="arithmatex">\(x-5=0\)</span>, dénominateur <span class="arithmatex">\(=11\neq0\)</span>, donc <span class="arithmatex">\(\boxed{x=5}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(x-7=0\)</span>, donc la valeur interdite est <span class="arithmatex">\(\boxed{7}\)</span>.</li>
    <li value="5">Le numérateur vaut <span class="arithmatex">\(2\)</span> et ne peut pas être nul : <strong class="auto-resultat">aucune solution</strong>.</li>
    <li value="6"><span class="arithmatex">\((x-1)^2=0 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( x-1=0\)</span>, donc <span class="arithmatex">\(\boxed{x=1}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Toujours contrôler les contraintes de définition avant de conclure.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Un quotient nul ne vient jamais du dénominateur.</div>

## Série D — QCM : équations et inéquations

<p class="auto-meta">⏱ 5 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification n'est demandée.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(3x-6=0\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(x=6\)</span></li><li><span class="arithmatex">\(x=3\)</span></li><li><span class="arithmatex">\(x=2\)</span></li><li><span class="arithmatex">\(x=-2\)</span></li></ol></li>
<li value="2"><span class="arithmatex">\(-4x&lt;8\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(x&lt; -2\)</span></li><li><span class="arithmatex">\(x&gt; -2\)</span></li><li><span class="arithmatex">\(x&lt;2\)</span></li><li><span class="arithmatex">\(x&gt;2\)</span></li></ol></li>
<li value="3"><span class="arithmatex">\((x+5)(x-1)=0\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(x=5\)</span> ou <span class="arithmatex">\(x=1\)</span></li><li><span class="arithmatex">\(x=-5\)</span> ou <span class="arithmatex">\(x=1\)</span></li><li><span class="arithmatex">\(x=-5\)</span> seulement</li><li><span class="arithmatex">\(x=1\)</span> seulement</li></ol></li>
<li value="4">La valeur interdite de <span class="arithmatex">\(\dfrac{1}{2x-6}\)</span> est<ol class="auto-choix" type="A"><li><span class="arithmatex">\(-3\)</span></li><li><span class="arithmatex">\(0\)</span></li><li><span class="arithmatex">\(3\)</span></li><li><span class="arithmatex">\(6\)</span></li></ol></li>
<li value="5"><span class="arithmatex">\(2x+1=5x-8\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(x=3\)</span></li><li><span class="arithmatex">\(x=-3\)</span></li><li><span class="arithmatex">\(x=\dfrac{7}{3}\)</span></li><li><span class="arithmatex">\(x=9\)</span></li></ol></li>
<li value="6"><span class="arithmatex">\(x^2=9\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(x=3\)</span></li><li><span class="arithmatex">\(x=-3\)</span></li><li><span class="arithmatex">\(x=3\)</span> ou <span class="arithmatex">\(x=-3\)</span></li><li>aucune solution</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Vérifier rapidement en remplaçant.</li><li>Pour les inéquations, surveiller le signe du coefficient.</li><li>Une équation peut avoir deux solutions.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas oublier la valeur interdite.</li><li>Diviser par un négatif change le sens.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(3x=6\)</span>, donc <span class="arithmatex">\(x=2\)</span>.</li>
    <li value="2"><strong class="auto-resultat">Réponse B</strong> : division par <span class="arithmatex">\(-4\)</span>, le sens change.</li>
    <li value="3"><strong class="auto-resultat">Réponse B</strong> : les facteurs donnent <span class="arithmatex">\(x=-5\)</span> ou <span class="arithmatex">\(x=1\)</span>.</li>
    <li value="4"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(2x-6=0\)</span>, donc <span class="arithmatex">\(x=3\)</span>.</li>
    <li value="5"><strong class="auto-resultat">Réponse A</strong> : <span class="arithmatex">\(9=3x\)</span>, donc <span class="arithmatex">\(x=3\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse C</strong> : deux nombres ont pour carré <span class="arithmatex">\(9\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Tester la réponse proposée dans l'équation permet souvent de contrôler.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Un QCM rapide n'autorise pas à ignorer les contraintes.</div>
