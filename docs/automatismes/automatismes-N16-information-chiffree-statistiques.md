## Série A — Réactivation – pourcentages et évolutions

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre rapidement. Utiliser les coefficients multiplicateurs dès que possible.
</div>

<ol class="auto-questions">
<li value="1">Calculer <span class="arithmatex">\(20\,\%\)</span> de <span class="arithmatex">\(450\)</span>.</li>
<li value="2">Augmenter <span class="arithmatex">\(80\)</span> de <span class="arithmatex">\(15\,\%\)</span>.</li>
<li value="3">Diminuer <span class="arithmatex">\(250\)</span> de <span class="arithmatex">\(12\,\%\)</span>.</li>
<li value="4">Passer de <span class="arithmatex">\(0{,}37\)</span> à un pourcentage.</li>
<li value="5">Un prix passe de <span class="arithmatex">\(40\)</span> à <span class="arithmatex">\(50\)</span> euros. Calculer le taux d'évolution.</li>
<li value="6">Calculer <span class="arithmatex">\(75\,\%\)</span> de <span class="arithmatex">\(64\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Hausse de <span class="arithmatex">\(t\,\%\)</span> : multiplier par <span class="arithmatex">\(1+\frac{t}{100}\)</span>.</li><li>Baisse de <span class="arithmatex">\(t\,\%\)</span> : multiplier par <span class="arithmatex">\(1-\frac{t}{100}\)</span>.</li><li>Pour un taux, comparer l'écart à la valeur initiale.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Le taux d'évolution se calcule toujours par rapport à la valeur de départ.</li><li>Ne pas confondre <span class="arithmatex">\(15\,\%\)</span> et le coefficient <span class="arithmatex">\(1{,}15\)</span>.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(0{,}20\times450=\)</span><wbr><span class="arithmatex">\(\boxed{90}\)</span>.</li>
    <li value="2">Coefficient <span class="arithmatex">\(1{,}15\)</span>, donc <span class="arithmatex">\(80\times1{,}15=\)</span><wbr><span class="arithmatex">\(\boxed{92}\)</span>.</li>
    <li value="3">Coefficient <span class="arithmatex">\(0{,}88\)</span>, donc <span class="arithmatex">\(250\times0{,}88=\)</span><wbr><span class="arithmatex">\(\boxed{220}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(0{,}37=\boxed{37\,\%}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\dfrac{50-40}{40}=0{,}25\)</span>, donc <span class="arithmatex">\(\boxed{25\,\%}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(75\,\%=3/4\)</span>, donc <span class="arithmatex">\(\dfrac34\times64=\)</span><wbr><span class="arithmatex">\(\boxed{48}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour une évolution, remplacer l'expression longue par un coefficient multiplicateur. Pour un taux : <span class="arithmatex">\(\dfrac{\text{final}-\text{initial}}{\text{initial}}\)</span>.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une baisse de <span class="arithmatex">\(12\,\%\)</span> ne signifie pas soustraire <span class="arithmatex">\(12\)</span>, mais soustraire <span class="arithmatex">\(12\,\%\)</span> de la valeur de départ.</div>

## Série B — Statistiques – moyenne, médiane, étendue

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Traiter les calculs sans calculatrice. Ranger les valeurs quand c'est nécessaire.
</div>

<ol class="auto-questions">
<li value="1">Calculer la moyenne de <span class="arithmatex">\(6;8;10;12\)</span>.</li>
<li value="2">Donner la médiane de <span class="arithmatex">\(3;7;11;15;20\)</span>.</li>
<li value="3">Donner la médiane de <span class="arithmatex">\(4;8;10;18\)</span>.</li>
<li value="4">Calculer l'étendue de <span class="arithmatex">\(12;5;9;18;7\)</span>.</li>
<li value="5">Dans une série, la moyenne de <span class="arithmatex">\(10;14;16\)</span> est-elle <span class="arithmatex">\(13\)</span> ?</li>
<li value="6">Une note <span class="arithmatex">\(x\)</span> complète <span class="arithmatex">\(8;12;16\)</span> pour obtenir une moyenne de <span class="arithmatex">\(13\)</span>. Trouver <span class="arithmatex">\(x\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Moyenne : somme divisée par effectif total.</li><li>Médiane : ranger la série.</li><li>Étendue : maximum moins minimum.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>La médiane n'est pas toujours une valeur de la série.</li><li>La moyenne est sensible aux valeurs extrêmes.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\dfrac{6+8+10+12}{4}=\)</span><wbr><span class="arithmatex">\(\boxed{9}\)</span>.</li>
    <li value="2">La valeur centrale est <span class="arithmatex">\(\boxed{11}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\dfrac{8+10}{2}=\)</span><wbr><span class="arithmatex">\(\boxed{9}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(18-5=\boxed{13}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\dfrac{10+14+16}{3}=\)</span><wbr><span class="arithmatex">\(\dfrac{40}{3}\)</span>, donc <strong class="auto-resultat">non</strong>.</li>
    <li value="6"><span class="arithmatex">\(\dfrac{8+12+16+x}{4}=13\)</span>, donc <span class="arithmatex">\(36+x=52\)</span>, <span class="arithmatex">\(x=\boxed{16}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Identifier d'abord l'indicateur demandé. Pour une médiane, le rangement est obligatoire ; pour une moyenne, l'effectif total doit être clair.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Sur une série de quatre valeurs, la médiane est la moyenne des deux valeurs centrales.</div>

## Série C — Séries avec effectifs

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Utiliser les effectifs. Ne pas oublier de calculer l'effectif total.
</div>

<ol class="auto-questions">
<li value="1">Valeurs <span class="arithmatex">\(2;5;8\)</span>, effectifs <span class="arithmatex">\(3;4;1\)</span>. Donner l'effectif total.</li>
<li value="2">Avec la série précédente, calculer la moyenne.</li>
<li value="3">Dans une classe : <span class="arithmatex">\(12\)</span> filles et <span class="arithmatex">\(18\)</span> garçons. Quelle proportion de filles ?</li>
<li value="4">Un groupe de <span class="arithmatex">\(20\)</span> élèves contient <span class="arithmatex">\(6\)</span> internes. Donner la fréquence des internes.</li>
<li value="5">Une série a moyenne <span class="arithmatex">\(15\)</span> et effectif <span class="arithmatex">\(6\)</span>. Quelle est la somme des valeurs ?</li>
<li value="6">Valeurs <span class="arithmatex">\(1;2;3\)</span>, effectifs <span class="arithmatex">\(5;3;2\)</span>. Quelle valeur est majoritaire ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Une valeur répétée compte plusieurs fois.</li><li>Moyenne pondérée : valeur <span class="arithmatex">\(\times\)</span> effectif.</li><li>Une fréquence est une proportion.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas diviser par le nombre de valeurs différentes.</li><li>Diviser par l'effectif total.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(3+4+1=\boxed{8}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\dfrac{2\times3+5\times4+8\times1}{8}=\)</span><wbr><span class="arithmatex">\(\dfrac{34}{8}=\)</span><wbr><span class="arithmatex">\(\boxed{4{,}25}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\dfrac{12}{30}=\)</span><wbr><span class="arithmatex">\(\dfrac25=\)</span><wbr><span class="arithmatex">\(\boxed{40\,\%}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\dfrac{6}{20}=\)</span><wbr><span class="arithmatex">\(\dfrac{3}{10}=\)</span><wbr><span class="arithmatex">\(\boxed{0{,}30}\)</span>, soit <span class="arithmatex">\(\boxed{30\,\%}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\text{somme}=\)</span><wbr><span class="arithmatex">\(15\times6=\)</span><wbr><span class="arithmatex">\(\boxed{90}\)</span>.</li>
    <li value="6">L'effectif le plus grand est <span class="arithmatex">\(5\)</span>, donc valeur <span class="arithmatex">\(\boxed{1}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour une série avec effectifs, construire mentalement un tableau : valeurs, effectifs, produits valeur <span class="arithmatex">\(\times\)</span> effectif, puis totaliser.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le nombre de valeurs différentes n'est pas l'effectif total.</div>

## Série D — Type épreuve anticipée – QCM statistiques

<p class="auto-meta">⏱ 5 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification n'est demandée.
</div>

<ol class="auto-questions">
<li value="1">Hausse de <span class="arithmatex">\(8\,\%\)</span> : A <span class="arithmatex">\(0{,}08\)</span> ; B <span class="arithmatex">\(0{,}92\)</span> ; C <span class="arithmatex">\(1{,}08\)</span> ; D <span class="arithmatex">\(8\)</span>.</li>
<li value="2">Baisse de <span class="arithmatex">\(30\,\%\)</span> : A <span class="arithmatex">\(0{,}30\)</span> ; B <span class="arithmatex">\(0{,}70\)</span> ; C <span class="arithmatex">\(1{,}30\)</span> ; D <span class="arithmatex">\(-0{,}30\)</span>.</li>
<li value="3">Moyenne de <span class="arithmatex">\(4;10;16\)</span> : A <span class="arithmatex">\(10\)</span> ; B <span class="arithmatex">\(12\)</span> ; C <span class="arithmatex">\(30\)</span> ; D <span class="arithmatex">\(8\)</span>.</li>
<li value="4">Médiane de <span class="arithmatex">\(2;5;9;13;20\)</span> : A <span class="arithmatex">\(5\)</span> ; B <span class="arithmatex">\(9\)</span> ; C <span class="arithmatex">\(13\)</span> ; D <span class="arithmatex">\(20\)</span>.</li>
<li value="5">Étendue de <span class="arithmatex">\(7;12;3;18\)</span> : A <span class="arithmatex">\(21\)</span> ; B <span class="arithmatex">\(15\)</span> ; C <span class="arithmatex">\(11\)</span> ; D <span class="arithmatex">\(18\)</span>.</li>
<li value="6"><span class="arithmatex">\(3\)</span> élèves sur <span class="arithmatex">\(25\)</span> : A <span class="arithmatex">\(3\,\%\)</span> ; B <span class="arithmatex">\(12\,\%\)</span> ; C <span class="arithmatex">\(25\,\%\)</span> ; D <span class="arithmatex">\(75\,\%\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>En QCM, éliminer les réponses impossibles.</li><li>Vérifier si l'on demande un coefficient, une proportion ou un pourcentage.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>La réponse <span class="arithmatex">\(0{,}08\)</span> n'est pas le coefficient d'une hausse de <span class="arithmatex">\(8\,\%\)</span>.</li><li>Pour un pourcentage, ramener à <span class="arithmatex">\(100\)</span> si possible.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">réponse C</strong> : <span class="arithmatex">\(1+0{,}08=1{,}08\)</span>.</li>
    <li value="2"><strong class="auto-resultat">réponse B</strong> : <span class="arithmatex">\(1-0{,}30=0{,}70\)</span>.</li>
    <li value="3"><strong class="auto-resultat">réponse A</strong> : <span class="arithmatex">\((4+10+16)/3=10\)</span>.</li>
    <li value="4"><strong class="auto-resultat">réponse B</strong> : la valeur centrale est <span class="arithmatex">\(9\)</span>.</li>
    <li value="5"><strong class="auto-resultat">réponse B</strong> : <span class="arithmatex">\(18-3=15\)</span>.</li>
    <li value="6"><strong class="auto-resultat">réponse B</strong> : <span class="arithmatex">\(3/25=12/100\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Le QCM demande surtout de reconnaître rapidement la bonne grandeur : coefficient, moyenne, médiane, étendue ou fréquence.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Un résultat numérique peut être exact mais répondre à une autre question.</div>
